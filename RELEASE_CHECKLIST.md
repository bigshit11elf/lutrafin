# Public Release Checklist

Lutrafin must not be publicly released until all applicable items are complete.

- [x] `LICENSE` contains the unmodified AGPLv3 text.
- [x] `package.json` contains `"license": "AGPL-3.0-only"`.
- [x] Copyright holder is finalized and placeholders are replaced.
- [x] Canonical public source repository is finalized.
- [x] About/Legal page contains license, source link and provider attribution.
- [ ] TMDB attribution including approved branding is reviewed against current TMDB branding rules.
- [x] TVmaze attribution is present.
- [ ] Further provider terms, especially TVDB, are reviewed.
- [ ] Rights to the Lutrafin logo and all assets are confirmed.
- [ ] Dependency licenses are reviewed for distribution compatibility.
- [x] `THIRD_PARTY_NOTICES.md` exists.
- [x] `SECURITY.md` exists.
- [x] `CONTRIBUTING.md` exists.
- [ ] Complete Git history is scanned for secrets.
- [ ] Any compromised tokens are rotated.
- [x] P0/P1 security fixes are implemented.
- [x] Security-related tests/checks pass.
- [x] Production build succeeds locally.
- [ ] Fresh installation from the public README is tested.
